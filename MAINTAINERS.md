# Maintainers

Pedro Guzmán is the initial author and maintainer of Vertical Route Language.

The project is intended to become an international community-maintained open source project. Maintainer access should be expanded through demonstrated, sustained contribution, respectful technical judgment, and alignment with the architecture and safety goals of the project.

## Maintainer Responsibilities

Maintainers are responsible for preserving the hexagonal architecture boundaries, reviewing route-domain changes with care, keeping tests self-contained, guiding releases, triaging security reports, and helping contributors work effectively across languages and regions.

## Adding Maintainers

New maintainers should be nominated by an existing maintainer and accepted by rough consensus among current maintainers. The decision should consider contribution quality, review behavior, reliability, and respect for the Code of Conduct.
